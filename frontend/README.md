# Agentic Learning Coach — Frontend

React + Vite frontend for the Agentic Learning Coach.

See the [root README](../README.md) for the full project overview, architecture, setup instructions, environment variables, and deployment steps.

## Quick start

```bash
npm install
cp .env.example .env   # leave VITE_API_BASE_URL blank for local dev
npm run dev
```

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Start the local dev server |
| `npm run build` | Production build (output: `dist/`) |
| `npm run lint` | Run ESLint |
| `npm test` | Run the Vitest suite |
| `npm run test:watch` | Vitest in watch mode |
